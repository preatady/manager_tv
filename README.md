# Manager TV - Quản lý thư viện Java OOP Web

Bài tập lớn quản lý thư viện bằng Java 21 + OOP + Web UI responsive.

- Không có đăng nhập.
- Backend Java dùng `jdk.httpserver`.
- UI HTML/CSS/JavaScript thuần.
- Có Dashboard, tài liệu, độc giả, mượn/trả, quá hạn và thống kê.
- `Dockerfile.vercel` dùng để deploy container Java lên Vercel.

Source deploy được đóng gói trong `.deploy/bundle.part*` để Vercel giải nén trong bước build.
